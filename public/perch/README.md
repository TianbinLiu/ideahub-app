# perch 角色贴图

`chibi.png` 是右侧栏 / 底栏激活态出现的 Q 版角色（见 `src/components/CharacterPerch.tsx`）。

形象与创作入口 `/create` 三张封面（`public/create/*.jpg`）是同一位角色：
银白长发 · 薄荷绿挑染 · 金色五角星发饰 · 青蓝大眼 · 藏蓝短披风 + 金色圆扣 + 白立领。

## 为什么是位图

目标画风是渐变上色 + 发丝高光 + 线稿描边的日系手绘感。这种质感来自逐像素的明暗过渡，
手写 SVG path 只能拼平涂色块 —— 试过两版矢量都败在这上面（不是画得不够细，
而是矢量平涂做不出上色）。所以改用生成图。

## 重新生成

用项目自带的方舟 Seedream（`src/ai/arkClient.ts` 里的 `MODELS.image`）出图，绿幕抠图后缩放。

提示词要点：

- **不要出现「少女」等词**，方舟会以 `InputTextSensitiveContentDetected` 拒绝整个请求。
  用「Q版卡通角色」这类中性表述即可通过。
- 明确要求 **纯正绿色 `#00FF00` 纯色背景、无渐变无阴影无图案**，方便抠图。
- 要求 **半身像、只到腰部**：腿在 ~50px 下只会缩成两根看不清的小棍，
  而且「手往前伸捧住图标」比「腿垂在图标前」更贴合「抱住图标」的诉求。
- 要求 **双臂向前下方张开做捧住东西的姿势**。

抠图阈值按「绿色优势度」`g - max(r, b)` 判定，而不是「颜色接近纯绿」——
AI 出的背景常有轻微明暗不匀，卡死一个 RGB 值会留一圈杂边。

★ 阈值必须**先量分布再定**。实测这张图是干净的双峰：背景 ≥160，角色 ≤40
（薄荷挑染最高，26），中间 50~130 只有几百个抗锯齿边缘像素。
第一次拍脑袋取 40/12，正好把挑染切进过渡带 —— 挑染被做成 50% 半透明还被去了色，
而这种损伤在 50px 的成品上几乎看不出来，只有量 alpha 才会发现。

处理流程：

1. `dom >= 130` → `alpha = 0`
2. `50 < dom < 130` → alpha 线性过渡，并把 g 压到 `max(r, b)` 去绿溢色（只在过渡带做）
3. `dom <= 50` → 原样保留
4. 按 alpha `trim` 裁掉四周空白 → 从底部裁到手部下沿 → 缩到 160 宽 → 调色板量化存 PNG

160 宽是渲染尺寸（最大约 50px）的 3 倍，够 3x 屏；调色板量化把体积从 52KB 压到 17KB，
在这个尺寸下看不出色带。

改图后记得同步 `CharacterPerch.tsx` 里的 `ART_W` / `ART_H`（用来算等比高度）。
