# createbtn 底栏 ➕ 上的宠物

见 [`src/components/CreatePerch.tsx`](../../src/components/CreatePerch.tsx)。
她是一只**常驻的 app 宠物**：一直在那儿轻轻呼吸，每隔 7–15 秒自己挑一个动作演一遍再回到待机，
切 Tab 也会立刻演一个。

| 文件 | 什么时候播 | 动作 |
| --- | --- | --- |
| `idle.webp` | 平时（**无限循环**） | 头极轻微歪一下、肩膀随呼吸起伏，手不动 |
| `wave.webp` | 随机 / 切 Tab | 右手抬到耳边挥手，开心大笑 |
| `peek.webp` | 随机 / 切 Tab | 上半身前倾、撑住身前，睁大眼睛凑近张望 |
| `cheer.webp` | 随机 / 切 Tab | 双手举过头顶欢呼，金色光点 |
| `nap.webp` | 随机 / 切 Tab | 下巴枕在手背上打盹，头顶飘一个白色小气泡 |

16 帧横排，单格 200px（渲染约 44px，4 倍余量）。

## 这不是「切 Tab 才蹦一下的挂件」

第一版就是那么做的 —— 一次性挂件、人比按钮还大、从底栏往上戳出 60px。方向错了：

| | `../perch/`（挂件） | 本目录（宠物） |
| --- | --- | --- |
| 职责 | **对这一次操作的即时反馈** | **陪着你** |
| 触发 | 图标激活的那一下 | 自己的定时器 + 切 Tab |
| 姿势 | 与图标一一对应、固定 | 随机轮换 |
| 时长 | 演完就消失 | 一直在 |

两件事，别混，也别把这套图挪去当挂件用。

## 构图的硬要求：手画在画面最下沿正中央

这条对贴图仍然有效（改版式不用重出图），只是它现在的作用变了 —— 见下一节。
手画歪了，缩到 38px 之后整个人就没有重心，怎么调 CSS 都救不回来。

## 2026-08：从「站在按钮背后」改成「和按钮并排」

原来她站在按钮背后、双手搭在按钮上沿。看着好，但**她要从底栏往上探出 40 多 px**：
顶沿落在离屏幕底约 98px，而首页的播放进度条在 50px、时长文字在 72–86px ——
她正正压住播放进度。装饰盖掉信息就是回退，所以改成并排。

现在的尺寸（`TabBar.tsx` 与 `CreatePerch` 的 props）：

| | 值 | 为什么 |
| --- | --- | --- |
| 按钮 | 28px（原 34） | 并排后两者要一起塞进五分之一条底栏（390px 屏上约 75px） |
| 她 | 38px 宽 × 40px 高 | 40 = 38 × 209/200，取 idle 那张最高的贴图当地板线 |
| 重叠 | 8px（`-mr-2`） | 手画在贴图横向 35%–65%，38px 下是 13–25px；重叠 8px 时按钮左沿落在 30px，压住右袖口有接触感，≥14px 就骑到手上、等于退回旧版 |
| 整组 | 58 × 40 | 完整收在 56px 高的底栏里，一点都不往上戳 |

加号本身**不画进贴图**：它是 `components/Icon` 的矢量 `plus`，15px 下依然锐利，
而且提示词里写死了「无任何文字、字母、数字、符号」。

## 四个反应动作都从 idle 接出去

生成时用 `aFrom: "idle"`（A 端点 = idle 的末帧），播放时**正播一次再倒播一次**
（`alternate` + 2 次迭代），结束正好停在第 0 帧 = 待机姿势，切回 idle 循环接得上。

只正播一次的话会定格在动作顶点（比如手一直举在头顶），下一帧切回 idle 就是肉眼可见的跳变。

## 重新生成

```bash
# IMGTOOLS 指向一个装了 sharp 与 ffmpeg-static 的目录（一次性工具，刻意不进项目依赖）
IMGTOOLS=/path/to/tools node design/gen-createbtn-sprites.mjs . [idle,wave]
```

★ **改 idle 就必须把四个反应一起重跑**：它们的 A 端点是 idle 的末帧，
只重出 idle 会让四个动作的起手式和待机对不上。缓存在 `design/createbtn-src/`（不入仓）。

脚本跑完会打印各姿势的单格宽高，照抄进 `CreatePerch.tsx` 的 `SHEET` ——
高度写错不报错，只会把角色拉扁。

★ 不要画单眼眨眼。实测这个模型最容易画崩的就是单眼闭合（闭眼弧线朝上反、还叠一道多余
睫毛线），`design/gen-create-covers.mjs` 里为此专门写了「双眼对称」的约束。
`nap` 那套是**两只眼睛一起闭**，所以没问题。

流水线与踩过的坑见 [`design/lib/sprite-pipeline.mjs`](../../design/lib/sprite-pipeline.mjs)。
