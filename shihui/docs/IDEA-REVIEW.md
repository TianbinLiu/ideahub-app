# 诗词视频教育 App —— 查漏补缺与落地方案

> 2026-08-12。针对原始想法六点逐条评审，补上没提到但会决定生死的部分。
> 成本数字全部来自 ideahub 2026-08 方舟实测价，不是拍脑袋。

## 一句话判断

方向是好的：**"每句诗一段画面 + 念对了才翻页"把背诵从任务变成解锁动作**，这个核心创意成立；
而且 ideahub 已经把整条"逐段生成视频"的流水线用真金白银跑通了，这个项目对你是**改造，不是从零**。
但原案有三块大空缺，重要性从高到低：

1. **儿童合规**——目标用户是未成年人，这条线决定产品形态，原案一个字没提；
2. **单位经济**——每首创作约 ¥2 的真实成本，免费策略与定价必须从这个数倒推；
3. **朗诵识别的可靠性**——核心交互压在儿童语音识别上，而它在国内真机上并不可靠。

## 原案六点逐条评审

### 1️⃣ 学诗模式（每句一段水墨视频，朗诵推进）

**认可**：这是全案最强的一点。画面与句子一一对应、朗诵驱动推进，
比课本插图强一个量级，"解锁下一句"天然就是复习循环。

**补缺**：

- **内容库是资产，不是功能。** 唐诗三百首 × 平均 6 句 ≈ 2000 段视频。
  按 seedance-pro-fast ¥0.5/段（6s/720p，实测价）≈ **¥1000 一次性成本**，完全可控。
  但必须**预生成 + 人工审校 + CDN 分发**，绝不能现场生成——
  AI 会把「床前明月光」的床画成席梦思，教育产品画错一次就被家长挂到小红书上。
  审校人力才是内容库的大头成本，把它当出版流程看待。
- **朗诵识别不能做成硬门。** 儿童发音（奶音、方言、抢拍）识别错误率高；
  国内可用的是火山 openspeech 流式 ASR（注意：**方舟没有语音产品线**，另一条线另配凭证）。
  正确姿势：**判定从宽（字符命中 60% 即过）+ 手动放行常驻可见**。
  学习产品里"卡住孩子"比"放过一次假朗诵"伤害大得多——这是产品决策，不是技术妥协。骨架已按此实现。
- **段间连贯的工程做法 ideahub 已验证**：逐段捕获上一段视频的**真实尾帧**作为下一段起拍帧
  （"设定尾帧"只是蓝图，成片不一定拍到那儿）。预生成内容库时同样按这个流程跑。
- **原案漏了"范读"。** 心盲症的孩子靠画面，听觉型的孩子靠示范。
  头部 100 首值得录**真人童声/播音配音**（一次性成本低、质感远超 TTS），长尾用火山 TTS。

### 2️⃣ 创作模式（三难度 + 逐句生成 + 朗诵发布 + 打分排行）

**认可**：低难度"词语拼接"设计得非常聪明——它同时是**防呆**（拼出来的句子不会太离谱）和
**防抄**（拼词过程本身就是"是孩子自己写的"的证明）。发布带娃朗诵音频是打动家长的杀手锏。

**补缺**：

- **排行榜必须分组**：同主题 + 同难度 + 同年龄段 + **按周滚动**。
  全局永久榜一周内就会被家长代写和大龄用户霸榜，新来的孩子看不到自己的名次就流失。
- **打分口径必须钉死**：rubric 由产品单方面定义（骨架立了切题/意象/韵律/心意四维），
  LLM 只负责填数——模型换代分数不能漂，否则榜单前后不可比。
  另加**低分保护**：60 分以下只给评语不给总分，儿童产品不做打击式反馈。
  技术注意：豆包 chat 必须显式关深度思考（不关 52s/次，关了 10s，实测）。
- **防代写坦然处理**：家长代写拦不住，接受它；但过程留痕（拼词轨迹、逐句时间戳）+
  低难度天然防抄 + 分组周榜，已把伤害压到可接受。永远别承诺"绝对公平"。
- **敏感词是 400 整个失败，不是降级**（方舟实测，换措辞都绕不过）。
  孩子的自由输入必须**前置**过审（本地词表兜底 + 服务端审核），
  失败提示要童向（"这句话画不出来，换个说法试试～"），不能把上游报错抛给孩子。
- **UGC 互看 = 内容社区 = 审核义务**：面向未成年人的内容**先审后发**是硬要求，
  文本和音频都要过机审 + 抽人审。这直接影响成本与上线节奏（见 MVP 切法）。

### 3️⃣ 积分 / 配额 / 订阅

**认可**：结构对。生成有真实成本，限量合理；用"背诗/分享换积分"让赚积分行为本身就是学习行为，正向。

**补缺**：

- **单位经济先算清**（详见下方速算表）：一首 4 句 ≈ ¥2。
  关键决策：**学诗全免费**（内容预生成，边际成本≈0）、**创作才耗额度**——
  这个不对称恰好引导"先学后创"的正确路径。
- **未成年人支付是雷区**：8 岁以下充值属无效民事行为，孩子拿家长手机充值 → 投诉 → 必退。
  支付动作只能放在**家长门**后面（见下方账号体系），并设单日限额 + 顺畅退款通道。
  这不是负担，反过来是卖点：「所有花钱的事都过家长」写在首页，家长才敢装。
- **订阅档位成立，但成本侧别订阅**：ideahub 实测结论是方舟自家订阅套餐比"按量 + 换便宜模型"贵，
  所以**成本侧走按量**；卖给用户的"高清档"（seedance-pro/2.0 系，¥1.9/段起）差价真实存在，
  作为付费点是成立的。

### 4️⃣ 动机（心盲症 + 成就感）

**认可**：两个动机都真实。双编码理论（图像 + 语言同时编码记得更牢）支持所有孩子受益，不止心盲症人群。

**补缺**：

- **心盲症适合当传播叙事，不适合当产品定位**——没有家长会先自查孩子是否心盲再下载。
  产品页说人话：「背得快、记得牢、愿意学」；心盲症故事留给小红书种草文。
- **排行榜是双刃剑**：对榜头是成就感，对榜尾是打击。必须配**非竞争性成就**对冲：
  学完的诗做成水墨卡**收藏册**、连续学习天数、可导出的「我的诗集」。
  孩子比不过别人时，还有"跟昨天的自己比"这条路。

### 5️⃣ 延伸（语文文章 / 英文 / 作文）

**建议：先不做，但架构留缝（已留）。** 诗词是 AI 视频的甜点：句子短、意象强、
水墨风格天然容忍生成瑕疵；长文章逐句生成的成本和时长都会爆炸，作文批改则是另一个物种。
骨架的数据形状（内容库-句-段三层）已兼容其它文体，等诗词闭环跑通再扩。
"小学没有统考、资料真空"的市场判断有道理，但那个市场的对手是名师内容不是工具——先用工具赢。

### 6️⃣ 推广（小红书投家长 + 抖音投泛流量）

**认可**：人群与渠道的判断对。

**补缺**：

- **分享出去的成品就是最好的广告**：每个导出视频片尾 3 秒带品牌 + 下载口。
  家长晒娃是自愿传播，边际广告费为 0。这要求**导出合成视频（画面+朗诵音轨+片尾）做得早**——
  它不是锦上添花，是增长引擎本体（ideahub 已有客户端合并的工程经验）。
- **教育广告红线**：广告法禁"承诺提分"。"从被留堂到第一个出教室"可以当故事讲，
  不能写成效果承诺；投放平台会查教育资质，备案先行（见合规清单）。
- **冷启动别指望 UGC 社区**：先当"工具 + 内容"用。精美的水墨诗词视频本身就是获客素材，
  拿内容库切片去 B 站/抖音发，社区等有人了再开。

## 原案没提、但会决定生死的四件事

### A. 合规清单（按优先级）

| # | 事项 | 要点 |
|---|---|---|
| 1 | **儿童个人信息**（<14 岁） | 《儿童个人信息网络保护规定》+ PIPL：监护人同意是硬前提；**孩子的朗诵音频是敏感个人信息**，公开发布须家长逐次确认 |
| 2 | **生成式 AI 备案与标识** | 面向公众的生成式 AI 服务需备案（用方舟当上游不豁免 App 自身义务）；《人工智能生成合成内容标识办法》要求生成视频显式标识 + 元数据标识 |
| 3 | **教育 App 备案** | ICP 备案 + 教育移动互联网应用备案双份 |
| 4 | **未成年人模式** | 时长提醒、宵禁时段、家长可控开关——内容社区形态下是审核重点 |
| 5 | **内容审核** | UGC 先审后发 + 举报通道 + 人工复审记录 |

由此反推的产品形态：**孩子端无支付、无私信、无自由文本评论**。
互动一律用预设短语（"夸夸弹幕"：写得真好/画面好美/我也要写），既合规又保护氛围。

### B. 账号体系：家长账号 + 孩子档案

原案没提账号是谁的。答案只有一个：**账号主体是家长**（手机号注册），孩子是账号下的档案（可多娃）。
注册、支付、发布、分享四个动作过家长门（家长扫码/密码确认）；学习与创作本身零门槛。
这同时解决合规（监护人同意）、支付（成年人操作）、传播（家长分享朋友圈）三件事。

### C. 等待体验：35~60 秒不能白等

一段 6s/720p 视频实测生成 35-60s，对孩子是永远。两招：

1. **逐句创作天然是流水线**——孩子写第 2 句时，第 1 句在后台生成（ideahub 工作流已验证这个节奏成立）；
   写完最后一句时前面全部就绪，感知等待≈一段。
2. 等待画面做成**研墨动画 + 本句字词小知识**，把等待变成学习时刻，而不是转圈。

### D. 音画同步：逐句打点，不是整轨硬贴

发布播放时"边听朗诵边看画面"要对得上。正确做法：**录音时逐句打时间戳**
（孩子本来就是逐句念的，句边界天然存在），播放按句对齐视频段；
整条音轨从头贴到尾必然越走越偏。骨架的 mock 播放器按固定时长翻页，接真视频后换成
`ended` 事件 + 句时间戳驱动。

## 单位经济速算（2026-08 方舟实测价）

| 项目 | 数字 | 依据 |
|---|---|---|
| 内容库（唐诗三百首） | **≈¥1000 一次性** + 审校人力 | ~2000 段 × pro-fast ¥0.5/段 |
| 用户创作 · 标准档 | **≈¥2/首**（4 句） | pro-fast ¥0.5/段 |
| 用户创作 · 高清档 | ≈¥7.6/首 | pro ¥1.9/段（付费档的成本底） |
| 首尾帧设定图 | ≈¥0.22/张 | seedream-lite |
| 打分（豆包 chat） | 可忽略 | 3 元/M 入 + 15 元/M 出 |
| 免费额度 5 段/天 | 上限 ≈¥2.5/DAU/天 | 只有创作耗额度，学诗免费边际≈0 |

**定价锚**：积分售价按成本 ×3 起（覆盖审核、失败重试与白嫖）；
订阅若含"每天一首高清"，月费 ≥¥30 才不亏。倒推结论：**免费策略的宽严是这个产品最重要的运营旋钮**，
所以报价单必须收口一处（骨架 `economy.ts`），前后端逐条对账（ideahub 的教训）。

## 技术方案：最大化复用 ideahub

**直接搬**（已验证的坑一个不用重踩）：

- 逐段三拍流程（写要求→出首尾帧方案→炼视频）与**真实尾帧承接**（`segmentGen` + `captureVideoTail`）
- TOS 产物 24h 失效、无 CORS → `/api/asset` 代理；能力探测看 Content-Type 不看状态码（Capacitor SPA 回退坑）
- 报价/结算两张表逐条对账 + 测试钉住；互动计数防刷收口（播放足秒去重、点赞幂等落盘）
- Capacitor 打包链路、versionCode 自检、sideload/play 双通道
- 媒体事件一律带超时（后台标签页 loadedmetadata 永不到达）

**新做**：

1. 内容库管线：批量预生成脚本 + 审校后台（先用表格人肉审）+ CDN
2. 火山 openspeech ASR（朗诵推进）+ TTS/真人音（范读）
3. 逐句录音打点与音画对齐播放
4. 家长门（确认弹窗 + 支付跳转）
5. 导出合成视频（画面 + 音轨 + 片尾）

**骨架（本目录）已落地的**：四页面闭环（学/创/广场/我的）、承接门禁与扣费收口、
词语拼接编辑器、Web Speech 朗诵判定（从宽 + 手动放行）、录音、确定性打分、
防刷幂等、水墨占位画面（mock 下可看可演示）。待接线清单见 `src/ai/real.ts` 注释。

## MVP 切法（三步，每步有生死指标)

| 阶段 | 内容 | 验证什么 |
|---|---|---|
| **MVP-0**（2~3 周） | 学诗模式 + 预生成 20 首精校内容 + 朗诵推进（手动放行为主），无账号纯本地 | 孩子是否**反复**用（次日/7 日留存）——核心体验成立与否 |
| **MVP-1** | 创作（先只做词语拼接）+ 本地打分 + **导出视频给家长分享** | **分享率**——增长引擎成立与否的生死指标 |
| **MVP-2** | 账号（家长门）+ 云端 + 广场 + 积分/支付 + 合规全套 | 付费率、审核成本 |

排行榜、积分、订阅全是**放大器**——放大的前提是"学得爽、创得爽、家长愿意晒"先成立。
社区最后做：它的合规成本最高，而前两步完全不需要它。

## 风险 Top 5

1. **生成质量伤教育口碑**（概率高×伤害高）→ 预生成 + 人工审校压掉大头；创作侧明示"AI 画的可能不完美"
2. **ASR 卡住孩子** → 从宽判定 + 手动放行常驻（骨架已落地）
3. **合规滞后被下架** → 社区后置、家长门先行、备案与首发同步启动
4. **成本失控** → 学免费/创限额（骨架已落地）、报价结算对账
5. **大厂跟进同质化** → 壁垒不在生成技术，在**审校过的内容库 + 学创闭环数据**，这两样都靠先发时间堆
