启梦 2.60

· 模板市场新增「工作流」页签：公开了制作过程的作品可以上架到这里当「工作流模板」——点进去看每一段怎么做的（示例视频就是那条作品），再按它铺成自己的流水线。
· 上架两条路：发布页勾「同时上架到模板市场」，或在作品编辑页的「制作过程」里上架 / 下架；只有公开着、且是当下这一版的制作过程才能上架。
· 被公开制作过程引用的示例视频模板，作者删除或下架时只会「退役」：不再出现在市场，但素材保留、用它的流程照常能出片；等没人引用了再删。模板详情页会把引用数说清楚。

QiMeng 2.60

· The Template market has a new “Workflows” tab: a video whose process is public can be listed there as a workflow template — open it to see how each segment was made (the video itself is the example), then lay it out as your own pipeline.
· Two ways to list: tick “Also list in the Template market” when publishing, or list / unlist under “Process” on the video's edit page; only a public, up-to-date process can be listed.
· An example-video template referenced by public processes is only retired when its author deletes or unpublishes it: it leaves the market, but its assets stay and processes using it can still render; delete it once nothing references it. The template page shows how many processes reference it.
