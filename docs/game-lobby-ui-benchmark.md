# 工坊对局大厅与对局界面 UI 对标（金铲铲 / TFT / 星铁「货币战争」+ 多人休闲）

2026-11-24 · 基线 `2f9cf8f9`（main）· **只调研与文档，不改代码**

这份文档回答两个问题：

1. **调研 A**：成熟自走棋 / 多人游戏的大厅 · 匹配 · 房间长什么样，拆成一张**组件清单**，逐条对照我们的大厅（`src/studio/game/ui/Lobby.tsx`、`RoomScreen.tsx`），并给"位置 + 做不做 + 优先级"。
2. **调研 B**：按金铲铲 / TFT 的结构，**我们缺哪些子页面与功能**（对局内 11 项、对局外 9 项），每一项写"为什么自走棋需要它 / 我们有没有 / 按我们 App 的特色怎么特制 / 优先级"。

**怎么调研的**：只读公开网页 —— 官方资讯、腾讯 / 米哈游官方页、社区攻略、玩家测评、维基。**没有装这三款游戏、没有登录任何账号、没有逐帧核对截图**。所以：

- 只写"文字与截图描述能还原"的部分；位置按**公开截图描述 + 攻略里的方位词**还原，统一折算成"九宫格 + 百分比"（按我们横屏 800×363 的可用视口；`safe-top` 实测 41px ≈ 11%，见 `src/index.css` 的 `.safe-top` 注释）。
- **只读到搜索结果摘要、正文没打开的**，标 ⚠未核实；官方页 JS 渲染读不到正文的，也标。
- 我们的代码事实以 `2f9cf8f9` 为准，引用到文件与行号。

**结论先行（5 条）**：

1. **我们的大厅骨架没问题，问题是它只有"一张三选一的入口卡"**。Lobby 的注释写明"不摆金币 / 券 / 血量"，这条判断在"对局读数"上对；但对标下来，大厅真正要回答的是**四件事**：我是谁（头像/等级）、我有多少钱（券/余额）、这局怎么开（模式）、跟谁开（好友/房间）。我们把后两件做得比谁都细（联机降级、陈旧数据不灰键），前两件一块都没有。
2. **"选模式"和"开始"必须拆成两步**。金铲铲是右下角「开始游戏」旁边一颗「匹配」，点开才是模式页；TFT 是右下「模式 + Play」。我们现在**点卡片即开局**，误触就进队列 —— 这是首屏最该改的一条（组件 #13）。
3. **匹配中三件套我们缺一件**：人数有、取消有、**预计等待没画** —— `lobbyStore` 的 `queue.etaSec` 字段已经拿到了，`Lobby.tsx` 只念了 `queued/need`（组件 #17，成本最低的一条）。
4. **房间该有的都有了，缺的是"人味的入口"**：二维码（`components/QrCode.tsx` 已有）、分享链接（`ShareSheet` 已有）、好友列表、房主转移提示。都不难，难的是好友系统本身（对局外 P1）。
5. **对局内最痛的不是视觉，是"没有出口、没有名单、没有倒计时"**：设置页 / 投降 / 玩家列表与举报 / 回合倒计时全无；而「✕ 结束对局」只清本机状态、不通知服务端（`store.endGame`，`src/studio/game/store.ts:436`）—— 联机局里这一下等于把房间丢在服务端自生自灭。**P0 五项见 §2.2**。

## 第一部分 调研 A：大厅 / 匹配 / 房间

### 1.1 三家的骨架还原

#### 金铲铲之战（手游，最贴近我们的一块屏）

按公开资料还原的主界面（**不是截图逐帧核对**，"货币/宝箱位置"未核实）：

```
┌──────────────────────────────────────────────┐
│                                    [⚙ 设置/投降]│  ← 右上角齿轮；投降也藏在这里
│                                              │
│  左侧竖排：事件 / 商城 / 宝库 …               │   中部：小小英雄 + 棋盘（主视觉）
│                                              │
│  [头像]                                      │
│  左下角 → 生涯总览（对局记录 / 资料 / 赛季）   │
│                              [匹配] [开始游戏] │  ← 右下角，两颗并排
└──────────────────────────────────────────────┘
```

- **主界面是安全区，只干"查信息 + 进功能"两件事**：查角色等级 / 货币 / 阵容，进日常活动、任务奖励、商城 [s2]。2021 年的资料里，主页面左侧有「事件」「商城」两颗按钮，回主页面领活动奖励也是从这里进 [s1]。
- **右下角「开始游戏」旁边还有一颗「匹配」**，点它才进"选择模式"页；那一页里是时空裂痕（匹配 / 排位）、英雄之黎明（匹配 / 排位）、狂暴模式、双人玩法、暮光之战 [s1][s7]。⚠ 模式列表是 2021 年的版本，今天多了团队排位 / 双人作战等，**具体列表未核实**，但"开始游戏 + 旁挂匹配"这个结构一直在用。
- **头像在左下角**，点开是「生涯总览」，里面三个页签：对局记录（默认最近 20 场，每局旁边有播放键 = 回放）、资料（胜率 / 平均排名 / 常用羁绊）、赛季 [s5]。
- **右上角齿轮 = 设置 + 投降**：投降键在设置里，不能一开局就投，要等一段时间；投降后名次按最后一名算 [s4]。
- **设置里还有「快捷语播报」**，快捷语本身在藏品栏里添加，加到左侧的「＋」号 [s6]。
- **组队**：团队排位两人成队进八人局，同队不会在局内相遇；房间左上角有「?」看规则 [s3]。自定义房间：房主点「邀请好友」勾在线好友，人满点「寻找对局」或「开始对战」[s8-2]（⚠ 只读到摘要）；组队招募是"队伍准备区左下方的小红旗图标"，点了自动往聊天频道发招募，房间也能生成二维码分享 [s8-3]（⚠ 摘要）。
- **商城 / 宝典入口**：官方活动公告写"活动入口：游戏主页面 → 商城 → 道具" [s8]。
- **玩家测评里两条很值钱**：① "UI 非常简洁，但官方把菜单分成两批，商城战利品一批、排行榜微社区另一批，两个菜单如果不细看根本找不到" —— 极简的代价是**功能不可发现**；② "每次加入对局都会有**小英雄被传送到战场**的动画，比端游加载界面更顺" [s4 页内测评] —— 进场动画对标的就是这一段。

#### 云顶之弈（端游 + 手游，两种信息架构）

- **端游 / 国服客户端**：Play → 云顶之弈 → 模式（匹配 / 排位）→ 确认 → 进队列 → **匹配成功后要点「接受」**，超时不接受会扣少量胜点并短暂冻结排队资格 [s24]（⚠ 只读到摘要）。PC 客户端有 ready check 弹窗，卡在其他窗口后面会导致"匹配到了却不进游戏" [s25]（⚠ 摘要）。
- **手游（2020 开测版）**：大厅"非常简单"，右上角三个符号分别是**好友 / 通知 / 设置**，左下角新手教程处可以切换**新手教程 / 匹配模式 / 排位赛**；主界面可以邀请好友、选小小英雄与棋盘；**载入页有 ping 值与读条** [s10]。
- **手游（2021 Mobalytics 版）**：右上角 好友列表 / 任务 / 通知 / 设置（设置只有音频与通用项）；**左侧是通行证奖励**；**右下角是模式切换 + Play**；点 Play 进 lobby，**点 + 号邀请在线好友**；中央 hub 选小小英雄 / 棋盘 / 表情 [s9]。
- **局内**（同一篇）：左上角六边形 / 宝箱在"羁绊"和"备战席装备"之间切换，右上角"剑"（战斗统计）与"人"（侦察玩家）两个图标，右上角笑脸是表情轮盘，商店在右、经验在左下、金币袋在右下 [s9]。
- **对标里都有、而且全是"状态类"功能**：投降（10 分钟后 Esc → Surrender 或 `/ff`）[s11]、举报（局内点喇叭静音，赛后在大厅举报）[s12]、观战（14.1 起右键好友 → Spectate Game）[s13]、回合倒计时（15.1 把 2-1 备战从 50 秒延长到 60 秒，说明备战有硬倒计时）[s14]、聊天与表情（Enter 开左上角聊天框，G 发表情）[s15]（⚠ 摘要）。
- **匹配区域**：手游设置里有"匹配区域"选项，可改成全区域匹配来缩短等待 [s16]（⚠ 摘要）——这是"区域/延迟"这一行的对标来源。

#### 崩坏：星穹铁道「货币战争」（它没有大厅，抄的是另外两样）

- 性质：3.7 版本（2025-11-05）起的**常驻单机自走棋**，与模拟宇宙并列；3 个位面逐层推进，初始小队生命值，行动值内没清完就扣血，血为 0 结束 [s17][s19]。
- 对局内：在"棋盘界面"里招募 / 布阵 / 穿装备；金币买角色（白绿蓝紫金 = 1~5 费）、买经验升人口、刷新 / 锁定商店；羁绊、星级、前后台站位、角色赋能；固定节点选「投资环境」与「投资策略」（整局增益）；有「攻略」键按当前阵容推荐角色与装备 [s17][s19]。
- 开局前：**「标准博弈」（按最高职级挑难度，赢了解锁新难度、提升职级、拿积分与晋升点）与「超频博弈」（更短的快速模式，难度跟着标准博弈的最高职级）** 两种模式；结算按剩余生命给评价；积分奖励双周重置 [s17]。进入时"选择博弈模式与环境增益" [s22]（⚠ 第三方摘要；官方玩法说明页是 JS 渲染，正文没取到 [s18]）。
- **它没有大厅 / 匹配 / 房间**。所以它对我们的价值只有两处：
  1. **开局前的"模式 + 难度 + 增益"选择屏** —— 对应我们的 4 人 / 8 人 / 自定义（再加"难度/风格"选择）；
  2. **局内仪表盘的信息密度** —— 金币 / 商店 / 羁绊 / 星级 / 投资策略各占一块，互不重叠。我们的 `GameHud` + `BagBar` + `ItemRail` 已经是这个路子，可以对照它把"当前投资/事件"也做成一块常驻读数。

#### 三个"可参考"的多人休闲游戏

- **Marvel Snap**：主屏明确分**上 / 中 / 下三段**。上段：玩家图标、收藏等级、Credits、Gold、赛季等级、任务进度；中段：中央「Play」开排位 + 当前卡组 + 段位 + 轮播新闻；下段：五个 tab（商店 / 收藏 / 主界面 / 游戏模式 / 联盟）；**左上角齿轮是设置**，语言也在里面 [s20]。这是我们"顶栏放身份与钱"最干净的一份参照。
- **Party Animals**：好友列表在**主屏右下角**；Locker（衣柜/仓库）在主屏入口；设置分 Sound / Control 等分栏 [s21]。它证明"社交入口不必在顶栏，可以在右下角常驻一颗"。

### 1.3 从表里读出来的五条判断

1. **大厅不是"模式列表"，是四件事**：我是谁（#2/#3）、我有多少钱（#4）、这局怎么开（#9–#13）、跟谁开（#22–#23、#37–#40）。我们现在只有第三件，而且把它做成了"点一下就开"。
2. **"选模式"与"开始"必须分开**（#13）。金铲铲把"开始游戏"和"匹配"并排，TFT 把"模式"和"Play"并排 —— 两家都在防误触，也在给"选中的是哪个模式"一个可见的位置。
3. **房间的四个动作缺一不可**：码（#22）、人（#24）、权限（#27–#29）、开始（#27）。我们四个都有，**缺的是"码的传播方式"**（二维码 / 链接 / 好友），这一块对标全是"分享优先"，我们只有"念给朋友"。
4. **匹配中三件套 = 人数 + 预计 + 取消**（#16–#19）。我们缺"预计"；而 `etaSec` 字段早就在 store 里躺着。
5. **对标里最值得抄的不是视觉，是"状态诚实"**：预计等待、超时兜底、接受对局、数据陈旧不灰键。**我们其实在"诚实"上领先**（五级联机降级、陈旧数据强制刷新、AI 补位明示），但这些话都挤在底栏一行小字里 —— 重做时要做的不是"学他们说真话"，是**把真话放到它该在的位置**（状态点 + 展开）。

### 1.4 动效 / 交互（16 条）

- **没有动画库**（`package.json` 无 framer-motion / react-spring），现有动效全是 `src/index.css` 里的 `@keyframes` + Tailwind `transition-*`；全局已有 `prefers-reduced-motion` 兜底（`index.css:406`），**新加的任何位移动画都要在那一段里登记**。

### 2.3 按我们特色特制的四条主线

这四条是把"缺口"翻译成"只有我们做得出来"的东西。每一条都尽量落到已有模块上，避免新造轮子。

1. **战绩 = 每回合影片拼成的回放条**。
   我们每一期交的都是真视频（`rules.submitRoundEntry` 存 `videoUrl`），金铲铲的回放是"重跑一局"，我们的回放是"把这一局你拍过的片子按顺序放一遍" —— 对视频 App 来说这才是原生形态。战绩卡上直接一条时间轴（第 1~N 期，单机最多 8），点哪期播哪期，末尾接"谁赢了"。

2. **投降 = 认输并保留本回合影片**。
   对标里投降 = 名次按最后一名、直接退出（金铲铲 [s4]、TFT `/ff` [s11]）。我们多一步：**已交的片不退、不删，进"我的作品 / 战绩卡"**。理由是这一期的片子是玩家花了 token / 券炼出来的（`data/gameTickets.ts`、`ui/GenSheet.tsx`），认输是认名次，不是丢资产。这条也顺手解决"退出对局丢片"的投诉。

3. **聊天 = 贴表情 / 贴卡片，不做自由打字**。
   固定快捷语（6 句）+ 贴一张卡面（卡库里的卡，别人能看到卡名与卡面）+ 看板娘 6 格表情（`faceExpr` + `public/avatars`）。好处：审核面小、横屏不弹键盘、贴卡本身就是我们的内容。**做之前先确认服务端房间能不能广播自定义事件**；不能就先只在本机播，别做半套。

4. **新手引导 = 跟着做一局**。
   自走棋最难的是第一局（金铲铲的玩家测评直接说"萌新来不及读" [s4 测评]）。我们有 `components/guide/tours.tsx` 的完整引导框架（20 条 tour + `data-guide` 定位），却**一条工坊/对局的 tour 都没有**。做法：固定 seed 的 4 人 AI 局，`GuideStep` 一步一个动作，走完发 1 张券（`gameTickets` 的发放走服务端懒发，别在客户端加钱）。

**另外两条"按特色"但优先级低**：赛季做成"工坊赛季卡"（可分享，复用 `ShareSheet`）；商店在大厅只卖形象 / 模板 / 卡面（局内卡池商店不搬出来）。

## 第三部分 风险 / 明确不做 / 未核实

### 3.1 明确不做（免得下一轮又讨论一遍）

- **不做天梯 / MMR**：服务端没有 rating，客户端自造一套必然和服务端两套口径。赛季只做"自然月 + 称号"。
- **不做自由打字聊天**：审核成本 + 横屏打字体验，收益远小于"贴卡 / 表情"。
- **不把大厅做成第二个工坊**：大厅只回答"怎么开这一局"；卡片库 / 商店 / 任务都是**抽屉**，不跳页（跳页会丢大厅状态与队列）。
- **不在大厅摆局内读数**：金币、血量、商店利息仍然只在对局里（`Lobby.tsx:10` 的原判断不改）。大厅的钱只有"🎟 券 + token 余额"。
- **不给"匹配区域"做假选项**：我们没有多区域，先只显示延迟。
