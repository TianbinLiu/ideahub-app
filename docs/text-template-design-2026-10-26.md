# 文字模板：只用文字 + 封面做视频模板（2026-10-26）

主人 10-26 点名：「再做一个视频模板」里加一条**纯文字 + 上传本地封面图**的模板制作，例子是一段带【全局设定】【时间轴 0-2s…12-15s】【全局约束】、
点名「图1 ~ 图4」的长提示词。主人「好，等设计出来再说」→「花」→「如果有未完成的任务则继续完成，需要做选择的话自行调研并决定」。
这一份是设计正本：拍板、付费小验读数、规则住在哪、P1 做了什么、P2 还差什么。

## 一、付费小验读数（2026-10-26，主人「花」，合计 ¥22.40）

素材是主人例子的中性改写版（Blender 界面 + 白色鼠标 + 成年角色；落地 → 递伞撑开 → 掀帽 → 右键特写惊讶 → 拖来斗篷换装），
4 张参考图按「图片1 斗篷 / 图片2 雨伞 / 图片3 上半身特写 / 图片4 全身」上传，480p 竖屏、出声。方舟直连、开发机 key。

| 发 | 档 | 正文 | 时长 | 结局 | 实扣 |
|---|---|---|---|---|---|
| L1 | 草稿（2.0 mini） | 2000 字纯文字 | 4 s | 受理、成片 | ¥0.93 |
| L2 | 电影级（2.5） | 2000 字纯文字 | 4 s | 受理、成片 | ¥2.72 |
| A | 电影级 | 936 字长版（【】标题 + 五段秒数） | 10 s | 成片 | ¥6.75 |
| B | 电影级 | 375 字短版（秒数） | 10 s | 第一次同步 400（见读数 6），重发成片 | ¥6.75 |
| C | 草稿 | 375 字短版（秒数） | 10 s | 成片 | ¥2.32 |
| D | 草稿 | 347 字「镜头1~4」 | 10 s | 成片 | ¥2.32 |

1. **方舟没有提示词硬上限**：2000 字两档都受理（受理即开跑，取消回 409）。500 字是官方「建议值」，也是 App 自己的上限。
2. **电影级照着 936 字长版五段全做了**，还画出了 Blender 界面边栏；短版顺序也对、细节少。⇒ 2.5 上长提示词不掉细节，文字模板段在电影级放到 1000 字（`economy.promptMaxOf(id, { long: true })` → `TEXT_TPL_PROMPT_MAX`）。
3. 四发都**没有**把【】标题画成屏幕上的字 —— 但体检仍建议改成「标题：」（一键改），因为【】里的词也会被当成要画的东西（「以【女仆装形态】落地」）。
4. 草稿档：按秒写的版本顺序对、节奏提前约 1 秒、丢了一拍；改写成「镜头1~4」四个镜头都做到。⇒ 只有电影级认秒数（`VideoTier.timecodeOk`），别的档把时间轴改写成「镜头N」（`textTemplate.timecodesToShots`），超过一段能放的 4 个镜头请作者合并。
5. **只挂临时参考图（不画帧、不挂卡）时，四张图都用在点名的位置**，角色长相跟全身图 / 特写一致。⇒ 有图位的文字模板段一张帧都不画（`drawPlan.textTplDraw`），零图位的只补画开头一张。
6. 方舟偶发同步 400「invalid image format … received ""」（它去拉我们图床的图没拉到）：不扣钱、重发就过。App 已按码把这类拒绝说成「参考图没拉到，再试一次」（`arkClient` 提交被拒分文字 / 图片 / 没拉到三种）。

## 二、拍板（主人那 11 条全按建议定 + 我按上面读数定的数）

- 电影级文字模板段上限 1000 字，其它档 500；超了**在花钱之前拦**，不截断（`segmentGen.promptRoomOf` 是唯一的预算函数）。
- 按秒写的时间轴只在电影级上跑；草稿 / 高清改写成「镜头N」。
- 一段临时参考图上限 3 → 4，**只给文字模板段**（`refMentions.extraRefMaxOf`）。
- 「图1 ~ 图4」在建模板时变成**有名字的图位**，正文改写成 `@名字`（`refMentions.rewriteSlotMentions`）；套用的人按名字补图，出片那一拍编成真实编号。
  不能留裸的「图N」：发送顺序是帧 → 临时参考图 → 卡图，编号必然错位（承接上一段时整体后移一位）。
- 内容规则 A∧B：露肤 / 去衣动作词（A）与年龄模糊的主体词（B）同时出现 = 不能上市场；只有 A = 上市场时进人工预审。本机自用不受影响，出片照常由模型审核（`textTemplate.textTplPolicyFlags`）。
  主人那段例子会被判成「不能上市场」—— 这是有意的（Play 的 undress 条款）。
- 上市场一律人工预审，审核员 = 主人；上架前作者按模板原样出一段当试炼；正文公开但**不随作品 / 配方外流**（发布前 `videos.stripLocalOnly` 拿掉）；作者收益不做。
- 分期：**P1 App 本机版**（不碰服务端，这一份）；**P2 服务端 + 市场**另开 PR，合并要主人「合」。

## 三、规则住在哪（一条规则一处实现）

| 规则 | 唯一实现 |
|---|---|
| 是哪一种模板（白模 / 文字 / 经典） | `data/templates.templateKindOf` —— 别再写 `!t.refVideo` 当经典 |
| 体检（空 / 命令参数 / 【】 / 引号 / 台词 / 时间轴 / 图位 / 内容规则） | `data/textTemplate.textTplFindings`，拦不拦存 `textTplBlocked` |
| 一键改的先后（先去引号、再改【】） | `textTemplate.applyTextTplFixes` |
| 时间轴 → 镜头 | `textTemplate.timecodesToShots` |
| 图位怎么认、怎么改写、名字能不能用 | `refMentions.templateSlotRefs` / `rewriteSlotMentions` / `refNameIssue` |
| 图位缺哪几张 | `refMentions.slotGaps`（参考清单的虚线格与出片前的缺图闸同一个） |
| 这一档跑不跑得了这个模板 | `textTemplate.textTplTierMiss` ← `templates.textTplTierMissOf`（作者那一屏、存模板、档位那一排、出片门禁都问它） |
| 存之前的定型与整份校验 | `templates.normTextTplSpec`（saveTemplate 里，最后一道） |
| 套用落成什么样的一段 | `flowStore.textTplAppendSpec`（报价 `textTplQuote` 与真扣同一个 nodeCost） |
| 出片前还差什么 | `flowStore.textTplIssue`（genNode 的闸、`TextTplBanner` 摆的是同一句） |
| 做法锁（切自定义 / 切出直出 / 按段套白模） | `flowStore.textTplLaneLocked`；摘出处只走 `detachTextTpl` |
| 图位上下文摘录 | `textTemplate.excerptAround` |

构建里 `scripts/check-text-template.mjs` 直接 import 这几个模块实跑正反例（规则改一条就去补一句正例、一句反例）。

## 四、P1 做了什么（App，本机）

- **入口**：模板货架那张「创建属于你的视频模板」卡 —— 白模那两条路开着时点进提取器第一屏，最下面多一条「只用文字 + 封面」（`VideoTemplateExtractor.onPickText`，只有货架给）；
  白模开不了（离线 / 老服务端）时直接开文字那一屏，卡也不再整张藏（`TemplateShelf.startCreate`）。卡上的话分两种（`TemplateCreateCard.video`），
  钱上那句改成「传视频的两条要花 token、只用文字 + 封面不花」。提取器引导升到 v3，多一步「没有视频也能做」（不带锚点：工作流页那份提取窗没有这一条）。
- **作者那一屏** `components/TextTemplateSheet`：① 写提示词（体检 + 一键改 + 每档放不放得下）→ ② 给图位起名（默认「素材N」，带正文里点到它的那一截）
  → ③ 规格（时长按时间轴自动取够、画幅、默认档；每一档跑不跑得了、为什么、多少钱）→ ④ 封面（本机压成 720p）与名字、简介、分类 → 存进「我的模板」。
  写了一半关掉不丢（模块级 parked）；**没登录不存**（本机模板库按人分开，没人登录时存进去的谁都看不见），点「登录后存进我的模板」去登录、回来接着存。
- **详情页**按种类分：文字模板写「文字模板 · 15s · 要补 4 张图」、出片键带价钱、列出要补的图位；「怎么做出来的」摆整段正文与每个图位的上下文；
  模型那一行多档时说「套用后只能在这几档之间换」；发布区照实说「只存在这台设备上，发布到市场要等下一版」；不自动弹白模那份引导。
- **套用之后**：一段参考图直出段，画布与工坊方案台各挂一块 `TextTplBanner`（出处 + 出片前还差什么 + 摘掉出处），画布上那排做法页签不摆；
  参考清单 `RefStrip` 把缺的图位画成虚线格「@名字」，点了按图位名补图；图位的图名字锁住、只能「换图」（`replaceExtraRefUrl`）；
  档位那一排把模板跑不了的档灰掉并说「只在这几档上跑：…」；直出车道那两句提示（推荐挂场景卡、承接时重写地点）对文字模板段不说（正文里已经写了）。

### 验过的

浏览器（离线 dev、英文界面、本机测试账号）：贴主人那段例子 → 体检认出 10 处【】、1 处引号、5 段时间轴（超 4 个镜头、只能电影级）、4 个图位、内容规则「不能上市场」；
一键改两颗 → 起名 → 规格自动 15 秒、只有电影级跑得了（⚡1.5M）→ 封面 → 存好；货架卡「文字 · 只能电影级 · 15s · 要补 4 张图」；详情页正文与图位；
另一条两图位、「镜头1/2」的模板：免费用户默认落在草稿（⚡77.0k），高清 / 电影级标会员档；「用这个模板出片」→ 画布一段直出段、横幅、两个虚线格，补一张之后名字锁住、剩一格。
两处在浏览器里看到才改的：图位上下文原来从行首截 80 字、长行末尾的「参考图1、2」被截掉（→ `excerptAround`）；没登录时存进去的模板重开就不见（→ 存之前先登录）。

## 五、P2 还差什么（服务端 + 市场，另开 PR）

- 服务端认文字模板：`BranchTemplate` 加 kind / prompt / refSlots，`POST /templates/text`，shared / mine 带 `kinds` 参数（老 App 不认文字模板，默认不下发），健康端点能力位 `textTemplates`。
- 试炼闸换证据链：作者本人、带 templateId、成片成功、发出去的文字包含定型后的正文（`textTplSig` 已经在段上记了指纹）。
- 人工预审 + 管理端下架 + 模板举报入口（今天模板既不能举报、管理端也没有下架入口）。
- 内容规则服务端照抄同一份词表（跨仓 spec 钉一致）；封面走现成的 `/api/uploads/image`。
- 没做的小事：没把「`!x.refVideo` 当经典」写成构建里的棘轮（今天剩下的 30 处全是「是不是白模」的问法，文字模板落在「不是」那边没有问题）。
