# 视频平台 UI 对标：模板入口、首页、分区、我的、小组件（2026-10-21）

主人原话：创建模板的入口只是一行「用户上传本地示例视频」的文字，太容易被忽略，要一个**有看板娘背景、写着「创建属于你的视频模板」**的入口；
并且去调研别的视频平台的创建模板入口、首页（播放页）、分区页、「我的」页，以及按钮 / 图案这类小组件是不是都有贴合平台特点的设计，
有的话按启梦的特点也做一套。

**怎么调研的**：五路并行（模板入口 / 首页 / 分区 / 我的 / 小组件），只读公开网页、官方帮助页、平台 H5 / 网页版（应用内浏览器，访客身份）
和第三方拆解文章；**没登录任何平台、没装任何 App**。所以「原生 App 今天长什么样」有一部分是推断，下面每节的「拿不准的」写明了。
每路的原始笔记（带出处）在会话草稿里，这份只留结论和落地。

本轮代码在分支 `claude/ui-benchmark-1021`（叠在还没合的 #407 工坊两层改版上）。

## 第一节 模板创建入口

### 别家怎么做

- **几乎每家都是两层入口**。第一层长在流程里、「做完顺手发」：CapCut 的 Post → Publish as Template、剪映导出后「发布到剪同款」、
  Instagram 发布前那个开关、TapTV「公开创作过程」。第二层是**运营位 / 招募卡**：剪映剪同款页的创作者计划 banner、CapCut 模板栏的创作者 banner、
  RunningHub 的插画头图激励页、PixVerse 的「Create Template」。只做第二层的很少，两层都有才完整。
- **对谁开放分两派**：剪映 / CapCut / Canva 先审资格（没通过看不到发布键，入口是招募卡）；Instagram / TapTV / RunningHub / PixVerse 人人能发。
  我们的白模模板人人能做、但要花钱白模化 ⇒ 入口该是「谁都能点、点之前讲清楚」的卡片，不需要「申请」。
- **视觉是同一个格式**：头图或插画 + 一句动词打头的标题 + 一个主按钮 + 一行好处 / 步骤。国内 App 普遍把 IP 形象放进运营配图、空状态和引导里。
- **文案**：都短、动词打头（Publish as Template / Create Template / 发布到剪同款），技术细节（我们那句「自己做好的白模片也行」）没有一家写进主标题，都放副标题或下一步。
- **入口上标奖励**：剪映、CapCut、RunningHub、PixVerse、美图都把「发模板能拿什么」写在入口附近。

### 主人的设想对不对

**方向对**：插画背景 + 「创建属于你的视频模板」+ 主按钮，和国内平台的招募卡、IP 形象用法一致，比原来那颗虚线文字按钮好得多。
要说清的一点：**没找到哪个视频平台在「创建模板」入口上用吉祥物的先例**——这是从国内 IP 形象的通用用法（运营配图、空状态）推出来的，不是照抄某一家。

### 做了什么

- 新组件 `components/TemplateCreateCard`，两种尺寸：
  - **大卡（hero）**：还没有自己的模板时。左边字、右边是创作入口那张「模板」封面（看板娘拿着人物卡站在白模人偶旁边，`public/create/mode-tpl.jpg`），
    左往右压暗托字。标题「创建属于你的视频模板」，副标题一句人话解释白模（不让新人先撞上「白模」这个词），三步预览 ① 传视频 › ② AI 换成白模 › ③ 发布到市场，
    主按钮「开始创建」。
  - **小条（slim）**：已经有模板时缩成一行「再做一个视频模板」（CapCut 也是按人的状态给不同大小的入口）。
  - 位置：模板货架顶上，**「模板市场」和「我的模板」两个页签都有**（原来只在「我的模板」，而大多数人逛的是市场）；只在服务端能做白模模板时出现（`blockoutCap`，与原来那颗按钮同一个闸）。
  - 原来按钮里「自己做好的白模片也行」那句**没删**，挪到卡片下面一行小字，并点名提取器里那条路的原话（漏了会让人把做好的白模片再付费白模化一次，2026-08-17 的教训）。
    那句话的后半是「每条路都要花 token，按下开始之前会先报出价钱」—— 自带白模片那条也收钱（只认人、不出片），只点名「白模化要花 token」等于说另一条不要钱。
  - 没登录点它 → 去登录页、回来还在这一页；会话还在确认中 → 一句轻提示，不把人送去登录页（`authState` 三态那条规矩）。
- 新手引导「模板」那一步改指这张卡（`data-guide="template-create"`）。

### 有意没做的

- **卡上不写奖励**。别家都写，但我们的同款奖励只发给「按作品 / 按配方做同款」（`flowStore.remixOf`），**套用模板不写 remixOf、不触发奖励**。
  写一句「别人用你的模板你能拿 token」就是许诺一件系统不兑现的事。要写，得先让服务端给模板作者也发奖（另一件事，见第七节）。
- **卡上不写价钱**。白模化的价格按原片时长算，点开提取器的第一屏照旧整句报准确价（`blockoutizeBlockReason` 那道套餐闸也在第一屏）。
  入口上能写的只有「起步价」，那是一个会被人当成实价的数。
- **流程内那一层（发布成功后「把这条做成模板」）没做**：要动发布页和提取器的入口参数，单独做。

### 拿不准的

剪映 / CapCut 入口原话多来自 2020–2022 年的帮助页与教程；CapCut 模板栏 banner 原话、Instagram 那个开关的原话来自第三方转述；Canva、PixVerse 文档抓不到。

## 第二节 首页（视频播放页）

### 别家都有、我们原来没有的

七家（抖音 / TikTok / 快手 / YouTube Shorts / Reels / B 站竖屏 / 视频号）对比，最大的缺口是**长按那一层**：2022–2026 年各家都把次要动作和负向动作
（倍速、清屏、不感兴趣、举报、保存、连播、画中画）从常驻按钮挪进了长按，右栏只留 4~5 个正向动作。长按还按区域分：
**按住两侧 = 临时 2 倍速**（抖音、YouTube、Reels、视频号、B 站都是），按住中间 = 菜单或倍速面板（抖音）。其它几样：右上角搜索（TikTok / 抖音 / Shorts）、
双击点赞的爆开动效带品牌色、计数折成「万」。

### 做了什么（`pages/FeedPage.tsx`、`components/FeedActionSheet.tsx`）

- **按住两侧（各 22%）= 临时 2 倍速**，屏幕上方出「2× 快进中」，松手恢复原来的速度；暂停着按住会先接着放。
- **按住中间 = 「更多操作」抽屉**：倍速 0.75 / 1 / 1.25 / 1.5 / 2（这一次在首页上各条共用，进度条右侧显示当前倍速；离开首页再回来、或重开 App 回到 1×）、清屏观看（就是右侧栏那颗全屏键；横屏片上写「转屏观看」，因为它会把手机转过来；已经在全屏里时这一行不摆）、
  保存到本地（只在能保存的环境出现，去详情页里选，那边的规则是唯一实现）、举报（原来只在详情页）。
  长按 450ms 触发、手指挪动超过 10px 算在滑、付费未解锁与不在屏上的那一条不给长按；关掉了画面上 WebView 的长按选字与系统菜单。
  从这一条作品名下弹出去的浮层（评论抽屉、弹幕输入条、举报框、做同款的确认卡）上的按压一律不算在画面上：评论框里长按照样能粘贴，确认卡上按久了也不会开出长按菜单。
  几个数（450ms、两侧 22%、临时 2×）在 `data/feedGestures`，新手引导里那句「临时 N 倍速」插的是同一个数。
- **双击点赞**：心形随机倾斜 ±15°，外圈 8 颗粒子（金色四角星呼应看板娘的星形发卡 + 品牌青的光点），只动 transform / opacity，减少动态效果时粒子不出。
  **双击不再顺手把视频停住**：第一下单击切过播放 / 暂停，第二下撤回来（抖音 / TikTok 都是边放边点赞；原来点完赞画面停在那儿）。
- 右栏的赞 / 评论 / 收藏数按「x.x 万」折（`formatPlays`，原来直接印 12345）。
- 右上角原来那块占位换成**搜索放大镜**，点了去分区页并把光标放进搜索框（第一次进分区时先让分区的引导讲完再给焦点）。
- 没登录时作者头像下也有关注「+」，点了去登录、回来还在首页（原来没登录就不显示，和各家不一样）。
- 「⚡ 做同款」换成自己的图形（见第五节）+「做同款」。付费锁定的遮罩换成矢量锁。
- 新手引导首页加一步「长按画面」。

### 没做的（及原因）

| 想法 | 为什么没做 |
|---|---|
| 不感兴趣 | 服务端没有这个端点；「点了没反应」的选项不摆（本仓规矩） |
| 右栏底部「旋转碟片」= 做同款入口（抖音碟片的启梦版） | 右栏高 512px + 底 104px，640 高的屏只剩 24px，要先删一颗键或减间距，得量过 |
| 按住滑下去锁定 2 倍速 | 与上下翻页的手势冲突，要真机调手感 |
| 进度条分段刻度 + 拖动时的帧缩略图 | 底部几何是锁定的，刻度不改高度但要真机看 |
| 视频下 / 评论区顶上的「相关搜索」 | 需要服务端给每条作品配一个查询词 |
| 评论区边放边看、左滑看作者作品栏、自动连播、画中画 | 各自是一件事，按需再排 |
| 收藏改成金色星（抖音式） | 主人定（第七节）：一旦星 = 收藏，全 App 的五角星就只能表示收藏 |

### 拿不准的

抖音当前右栏（收藏星、碟片）与顶部页签、TikTok 爆心的倾角、下拉刷新与清晰度选择都没在本次会话里一手核到；TikTok 帮助中心是 JS 渲染、读不出来，长按菜单的细节来自新闻报道。

## 第三节 分区页

### 别家怎么做

- 第一屏一律是**顶部搜索框** + 分类入口 + 热榜 + 双列作品流。分类多就用可滑动的文字芯片（B 站），只有几个重点入口才用带图标的宫格（「金刚区」5~10 个）。
- **点进搜索框、还没打字时**统一是三段：搜索历史 + 猜你想搜 + 热榜。热榜每行：名次 + 标题 + 热度，前三名换色。
- 双列卡片：封面底部压一条渐变，左下播放量、右下时长，下面两行标题 + 一行灰色的作者；「推荐理由」角标只给少数条目。
- AI 视频平台（即梦、可灵、Sora）的发现页和「做同款」绑在一起。

### 做了什么（`pages/DiscoverPage.tsx`、`data/searchHistory.ts`）

- 搜索那一行**钉在顶上**；点进框里还没打字时铺开**搜索历史**（本机、按账号分开存、最多 10 条，可清空）和**近期热播**（最近发布的作品里播放最多的 8 条，前三名金色名次）。
  框里有字时回到原来的结果页（人在前、作品在后）。旁边「取消」收起键盘与面板，框里的词留着；✕ 清空之后光标回到框里（抖音 / B 站都这样）。
- 六个看板娘分区入口**最前面加「全部」**（原来只能「再点一次取消」），选中态与其它分区同一套。
- 卡片按 B 站格式重排：封面底部渐变，左下 ▶ 播放量、右下时长，右上 AI 生成（合规必须，位置挪了没去掉），左上「示例 / 互动」；
  下面标题 + 16px 头像、作者名、赞数。近期热播那一排每行也带 AI 生成标识（面板开着时下面的网格不画，那一排就是此刻屏幕上的发布内容）。
- 空态换成看板娘：没东西 = 睡着的那张，搜不到 = 歪头那张，并给「去创作」。
- 新手引导补了搜索历史与「全部」。

### 没做的

- **热词占位、猜你想搜**：要服务端下发热词。
- **服务端热榜**：现在的「近期热播」是本机拿到的最近一批作品按播放排的，作品多了就不是「全站最热」——要服务端给排行接口。标题写的是「近期热播」、副标题照实说「最近发布的作品里播放最多的几条」。
- **卡片上的「N 人做了同款」**（AI 平台特有的推荐理由，原本做了）：列表端点不带 remixCount（契约：只有详情端点算），分区页的作品全是列表那一跳来的，摆上去永远不会出现 —— 撤了。要做得先让服务端在列表里按页聚合。
- 「同款最多」排序、本周 / 全部时间窗口：要服务端能按 remixCount 排。
- 往下滚之后把分区插画行收成一条紧凑芯片条、骨架屏：下一轮。

### 拿不准的

TikTok 搜索筛选项、抖音快手 2025~2026 的搜索页现状、小红书频道栏没核到；即梦 / 可灵 / 海螺发现页的布局没有一手资料。

## 第四节 「我的」页

### 别家怎么做

- 两派：国内（抖音 / 快手 / B 站 / 小红书）有通栏头图、信息密（ID、IP 属地、标签、等级），钱包和创作者中心放进 ≡ 抽屉；海外（TikTok / Instagram）没头图或只有内嵌圆角头图。
- 统计 2~3 组「大数字 + 小标签」，**自己看和访客看是同一套、同一个顺序**。
- 自己：一对中性按钮「编辑资料 / 分享主页」；访客：一个品牌色「关注」+ 次要按钮。
- **锁只表示「只有你看得见」**（抖音「喜欢🔒」、TikTok Liked），没有一家拿锁表示草稿。
- 合规：《互联网用户账号信息管理规定》第十二条要求账号信息页展示 IP 属地，抖音已展示。

### 做了什么（`pages/ProfilePage.tsx`、`components/MagicBand.tsx`）

- 头像后面加一条**矮的品牌带**（88px：青色渐变 + 三圈法阵线 + 四颗金色四角星），不挡作品墙出现在第一屏。纯装饰、点不到。
- **草稿不再用锁**：页签和草稿卡角标都换成笔；锁只留给作品墙上「仅自己可见」那一枚。新手引导那句「那把锁是还没发布」同步改了。
- 修了两个原有的问题：
  - 页签行钉在顶栏下面的偏移原来写的是 44px，而顶栏实际高 59px（10px 安全区留白 + 48px + 1px 边线）⇒ 往下滚时页签行有 15px 压在顶栏底下。现在按 59px 钉，浏览器里量过正好贴住。
  - 作品墙格子右下角「回炉过 / 第 N 版」与「AI 生成」两枚角标会叠在一起，现在上下排。
- 访客页加「拉黑」（原来只能去作品页）。
- 「点按复制」的小字换成 slate-400（对比度规矩）；卡片 / 卡组 / 收藏 / 作品确实为空时用睡着的看板娘；「没能取到」「这个用户可能注销了」那几句不放（没问到 ≠ 没有，注销是禁区）。

### 没做的

- **统计口径统一**（自己看也有「粉丝」、访客看同一套）：服务端要在「我」的回包里给粉丝数。
- **IP 属地**：合规上大概率要做，需要服务端字段，展示范围先问法务（「合理范围内」的口径）。
- ≡ 抽屉收纳右上角四颗键、创作者中心、置顶作品、「以访客身份预览」、自定义头图、「模板」页签：各自一件事，按需排。

### 拿不准的

原生 App 里「自己的主页」没法直接看（只能看网页 / H5 的访客视图）；抖音的草稿格、TikTok 的 ☰ 菜单、B 站「我的」页的硬币 / 服务宫格是凭记忆、没核到。

## 第五节 小组件：按钮与图案

### 别家的规律

1. **通用动作用通用图形**：点赞、评论、分享、搜索、首页、返回各家几乎都是同一个造型。真正特化的只有**平台独有的动作**：B 站投币、Medium 拍手、
   抖音的碟片（拍同款入口）、网易云的黑胶。判据：这个动作别家没有，才值得画专属图形，而且要配文字。
2. **品牌感主要放在反馈动效和颜色里**（点赞爆开、B 站三连绽放），不放在常驻图标的造型上。
3. **吉祥物出现在边缘位置和情绪时刻**（闪屏、空状态、奖励、引导、断网页），高频功能框架里反而做中性；涉及钱、安全、法务的时刻不开玩笑、不放吉祥物。
4. 选中态通行做法是「线性 → 实心」。

### 做了什么（`components/Icon.tsx` 等）

- 只给启梦**独有的概念**画了三枚招牌字形（线性 + 实心两套，24 网格、描边粗细与现有一致）：
  - **做同款** `remix`：叠在一起的两张塔罗卡，前面那张带一颗四角星（首页右栏那颗「做同款」）。
  - **工坊** `workshop`：扇形展开的三张卡，中间那张带星（底栏）。
  - **分区** `discover`：指南针，指针画成四角星（底栏）——外形仍认得出是指南针。
- 通用动作补了两枚通用图形：`flag`（举报）、`gauge`（倍速）。首页、我的、点赞、评论、分享、搜索照旧用通用图形。
- 我的仓库那三张「造卡」入口卡的 emoji 换成矢量图标（卡组 / 卡片 / 上传）。
- 双击点赞的粒子（见第二节）是品牌放进反馈动效的那一处。

## 第七节 等主人定的事

1. **收藏改成金色星吗**（抖音式，呼应看板娘发卡）？改了之后全 App 的五角星只能表示收藏，AI / 生成一律用四角星。
2. **模板作者要不要也有奖励**？别家入口上都写奖励。我们现在只奖「按作品做同款」，套用模板不算——要奖的话是服务端的新规则（发不发、发多少都在服务端判，App 只说那一句）。
3. **IP 属地**要不要做（合规），展示到省还是更粗，先问法务。
4. **右栏「做同款碟片」**：要做就得在右栏里拿掉一颗键（建议把「全屏」挪进长按菜单，它现在已经在里面了）。
5. **不感兴趣**、**热词 / 服务端热榜**、**粉丝数统一口径**：都要服务端接口，排不排期。
