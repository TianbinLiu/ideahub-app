## 0. 出片结算（已拍板，替换原 §四"游戏券"的说法）

- **免费套餐每月 6 张游戏券**（按月算，不是每天）＝每月能真出 6 条片；
- 另外**任务加券**：分享 App、邀请新用户等（沿用现有任务/邀请奖励体系，具体数额后续定）；
- 券只用于"游戏内出片"，**不扣 token 钱包**；券用完这一局就用占位片打完。

## 1. 模型：工坊默认档必须"能用全部卡类型（含真人卡，但不含需要真人授权认证的那种）"

- 目标：**最便宜的一档也能挂写实/真人角色卡**（不含需要"火山引擎适用/真人授权"那一类认证素材——那种卡永远不进游戏）；
- 要核实（写结论到 `docs/g2-game-ui.md`）：
  1. 我们档位表里哪几档 `refImg`/`realFace`/`assetRef` 的组合满足"不认证也能用真人卡"；
  2. 最便宜满足条件的档（优先 MiniMax H3 Lite 480p，真机实测它收写实人像、Seedance 会拦）；
  3. 若最低档不能满足，写清差在哪、需要加什么（如 `realFace:false` 的白名单）；
- 结算落到 `rules.generationTierOf`：L1 的返回值按这个结论改。

## 2. 3D 桌面（对照 `6927b7997cadc-2747838665.jpg`）

- **删掉左上角退出按钮**；
- **删掉右上角的重命名、问号、保存按钮**；
- 右上「工作流」按钮改成**纯预览**：打开后只**展示玩家当前每段视频的信息**（相当于把桌面上原来的节点卡搬进工作流面板），**删掉"修改/重新生成片段"等功能**；
- 桌面上的节点卡改成**空位**：玩家从背包把卡拖进空位，**只允许 4 个角色位**（4 张角色卡）；
- 角色位那一排的**左上方、低于桌面中线**加 1 个**场景卡位**；
- 摆完卡 → 点「视频生成」→ 弹小窗输入提示词 → 用"桌面上的卡 + 提示词"生成一段视频；
  - 提示词里**角色卡与道具卡的名字要能被视频模型识别**（把卡名拼进提示词，按现有 `idLine` 机制走）；
- **商店按钮移到背包栏右侧**；点商店 →
  1. 相机**移动并靠近 NPC**（复用现有"点 NPC 模型 → 相机拉近 + 滑动绕模型"的功能）；
  2. 商店栏出现在**屏幕上方**（对照 `068eec...png`），购买角色卡；
  3. **限制绕行角度：只能 NPC 正面 180°**，不能转到背后看模型后背；
  4. 点商店栏外面或再点商店按钮 → **收起商店栏 + 相机恢复原位**；
- 利息显示搬到**商店按钮里面**：只留利息图案 + 数字；
- 屏幕最上方放**对局进度条 + 当前生命值**；
- **删掉**左侧「卡组 / 翻开卡组 / 摊开在桌上」那一栏；
- **删掉**右侧「对局 / 市场」那一栏；
- **删掉**这些文案：暂无连胜、第一回合、商店、L1 草稿 480p、存活 4 人。

## 3. 背包与道具

- **删掉背包卡片的"按种类数量上限"**（角色≤4/场景≤1/道具≤4 这套以桌面卡位为准，不再按种类计数）；
- 道具卡限制改为：**每个角色卡最多挂 3 张**（对齐货币战争）；
- 道具卡显示在**屏幕右侧**（对照 `6927...jpg`）；
- 右侧同样有**拆除工具**：可拖到某个角色卡上，**一次卸下该角色卡上的所有道具卡**。

## 4. NPC 对话

- 对话选项里的「添加素材」「逛市场」**删掉**，只留「记录」和 NPC 对话气泡；
- NPC 说话音色**恢复成改动之前的行为**：按 App 设置页面的声音设置（当前设备是「清冷高雅 2.0」）。

## 5. 事件选择界面（对照 `f5b676...jpg`）

- 事件卡改成货币战争那种：一整块面板、三张卡横排、每张带图标 + 标题 + 花费/收益 + 一行说明；
- 选中态明显，确认按钮在面板底部；
- 免费/跳过选项要跟另外两张**同样排版**（不要缩成一行小字）。

## 施工顺序（建议）

1. **清理与布局骨架**：删按钮/删两栏/删文案、利息进商店键、顶部进度条+血量、桌面 4 角色位 + 1 场景位；
2. **商店流程**：按钮移位、相机拉近与 180° 限制、商店栏上移、点外收起；
3. **摆卡与出片**：拖卡入位、道具 3 张上限、右侧道具栏 + 拆除工具、生成小窗（卡名进提示词）、工作流面板改纯预览；
4. **NPC 对话**：删两个选项、音色恢复；
5. **事件界面**排版。

每步一个 PR，`npm run build` 必绿、i18n 同 PR 补 en、不提交截图。
