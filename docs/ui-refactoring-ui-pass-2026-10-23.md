## 三、这次改了什么（app#423）

按规则编号归类；每条都是「查过那行代码」才动的。

**⑥ 按钮层级**
- 作品页：`✏️ 编辑` 退成中性胶囊（原来是琥珀色，一个普通动作占了警示色）；`做同款` 与制作过程页的「按这个流程做同款」

- 发布页：`发布 / 替换原作品` 改成占满一行（`flex-1`），「放弃本次合成」保持次级；回炉态那句「会替换《…》的内容」升成琥珀提示条（原来是一行裸琥珀字，就在主键上方）。
- 剪辑页：两颗青色整宽主键（配音 / 按圈选重拍）改回 `bg-brand`（一页两种「主色」）；合好之后的「↩ 回去改」退成次级键。
- 工坊市场：三列卡片每张底下那颗实心 `bg-brand`「＋ 添加」改成淡色 `bg-brand/15 text-brand`（一屏 9~15 颗实心主键）；模板货架每张卡的「用它出片」同样改淡（字号按约定补到 `text-sm`）。

**③④ 字重与弱化**
- 评论（抽屉与作品页）：作者名 `font-medium text-slate-300`，时间留 slate-500（原来名字与时间同色同重）。
- 首页信息块：作者名 `font-medium text-white/90`（原来与标题一样纯白加粗，只差 2px 字号）。
- 新手引导卡上的 `1/7` 计数：从品牌色胶囊退成灰字（它不是能点的东西）。
- 素材入口角标：张数从 `bg-rose-500`（报警红）改成 `bg-slate-100 text-ink`。

**⑬⑭⑮ 灰阶、对比、别只靠颜色**
- 报错一律 `text-rose-300`：封面工坊三处 `text-red-400`、首页做同款失败那句琥珀、挂卡合成失败（画布与 FlowPage）两处琥珀。
- 未选中的筛选芯片 `text-slate-400` → 约定的 `text-slate-300`（工坊 / 我的 / 模板 / 画布选卡四处）。
- 设置页分组标题 slate-500 → slate-400（ink 底上 slate-500 只有 3.98:1）；列表分隔线 `divide-slate-800` → `divide-slate-700/60`。
- 发布页可见性三选一：选中那格多一枚 ✓（原来只靠边框变色）。
- 素材抽屉的「卡片 / 卡组」分段控件改成约定的选中态 `bg-brand font-semibold text-ink`。

**⑯⑲ 提示条与边框**
- 提示条统一 `border-<色>-500/40 bg-<色>-500/10`：发布页三处 `bg-amber-400/10`、发布 / 编辑页 `border-amber-400/50`、我的页 `border-rose-500/50`、取回卡与模板到期条 `border-amber-500/50`。
- 我的页五处卡片边线 `/60` 或裸 `slate-700` → `/70`；卡片页签那张瓦片 `rounded-lg` → `rounded-xl`。
- 抽屉标题 `text-base` → `text-sm`（关注 / 钱包 / 选头像 / 调整头像 / 草稿），关注与钱包两张抽屉的裸 `<Icon close size=20>` 换成 `CloseButton`（44px 命中区）。

**⑱ 尺寸与命中区**
- 剪辑页预览的播放键从 26px 命中区放到 44×44；首页「互动 · 你来选 / 做同款」两颗 28px 高的芯片加 8px 隐形热区；
  登录页两条文字链 `py-1` → `py-2.5`、同意协议的勾选框 36 → 44px；评论「回复」键补纵向热区并与同排三颗对齐。

**⑳ 空状态**
- 制作过程页离线时原来是一行红字「没能取到制作过程（离线模式：未配置 VITE_API_BASE）」+ 重试 —— 环境变量名上了屏。`fetchRecipe` 多一档 `offline`，
  页面与编辑页各说一句「需要联网」；`api/client` 那句兜底报错改成人话（排查认 code `OFFLINE`）。
- 画布选卡窗 / 选模板窗的空态从一行灰字改成 `EmptyState`（带去市场 / 去我的仓库 / 去模板市场的键）；关注列表空态同样；模板货架空着且能做模板时给「做一个模板」键；登录页探能力那行改用 `EmptyState loading`。

**① 文案口径（开发用语上屏）**
- 「⚠ 渐变回退」→「⚠ 没出成片 · 画面过渡代替」；「服务端会转存为长期地址」→「发布后会换成长期地址」；「否则出片会被整句拒」→「否则这一段出不了片」（两处）；
  「云端语音没出声（状态码）：…或到火山控制台看额度」→「云端语音暂时出不了声，稍后再试」；语音识别失败去掉 `HTTP ${status}`；
  「Seedream 真实生成」→「AI 真实生成」；「1～3 味豆包音色」→「1～3 种音色」；钱包「add-on token」→「加购 token」。

## 九、第五批：三件待定项由我调研后定（同日，app#427，随 2.68 发版）

主人：「先做，决策由你调研后决定，并且合 + 发版」。

**① 页面卡片要不要拆边框 —— 定：不拆，只拆嵌套的那一层。**
- 量出来的数：`ink #0b1020` 与 `panel #111a33` 的对比 **1.10:1**，`raised #192645` 对 ink **1.27:1**。书里「用两种底色代替边框」（§8.5.2）的前提是灰阶够细、两级底色肉眼分得开；
  GitHub 深色（canvas 对 panel 约 1.18:1）与 shadcn 深色主题（slate-950 对 slate-900 约 1.13:1）都在这个量级，**两家都保留了卡片边框** —— 深色界面里投影看不见，边框是分层的主要手段（§6.4.1 的反面）。
  要让纯底色分层成立得把 panel 整体调亮一到两档，那是全仓肉眼回归的活，收益是少几百条 1px 线，不值。
- 拆了的是**卡里套盒**（§8.5.1「边框 + 底色 + 阴影别叠在同一个元素上」）：8 处 `border border-slate-700 bg-black/25` 的内层盒子去掉边框，底色那一级差（黑 25% 压在 panel 上）足够。输入框的边框不动（那是「这里能输入」的形状）。
- 结论写进 CLAUDE.md 卡片容器那条：边框留着是量过的决定，不是没来得及。

**② 语义色别名 + 品牌色阶梯 —— 定：做，并且做成零像素变化。**
- `tailwind.config.js`：`danger = colors.rose`、`warn = colors.amber`、`ok = colors.emerald`、`info = colors.sky`（同一张表换个名字）；`brand = { ...sky, DEFAULT: #38bdf8 }`、`gold = { ...amber, DEFAULT: #fbbf24 }`
