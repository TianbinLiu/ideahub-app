# MJ 宇宙那类 AI 短剧是怎么做的 —— 调研与「快速模式」差距表（2026-11-22）

> 起因：主人指定复刻 B 站「灭霸和复联一起玩求生之路毫不留情」（BV1Thsz6QEgd，UP 冰素HL，134 万播放，
> 5:39，含 AI 生成内容标注），并问「别人用的是 updream，他们是怎么做的」。
> 本文是对照调研 + 我们自己那次真机复刻失败的结论，**不涉及任何版权素材的搬运**。

---

## 一、结论先说：这类片子不是"一句话出片"，是"图先行、逐镜出片、剪辑台上加台词"

把公开教程、updream 的产品说明、以及我们自己在 `docs/competitor-canvas-skill-mapping.md` 里记的
updream / LibTV 对比放在一起，做法是一致的：

1. **剧本 → 分镜表**：Agent 把一句话扩成 8~20 个镜头，每镜带**结构化字段**（镜号 / 时长 / 场景 / 景别 / 运镜 / 情绪节拍）。
2. **角色先锁死**：角色库 + **三视图**（正 / 侧 / 背）或多机位图；每镜挂同一张角色参考图 —— 这是"十二个镜头看起来像一部片子"的唯一办法。
3. **每镜先出关键帧图**：用图像模型（Seedream / MJ / Nano Banana 等）出静帧，**人在这一步挑图**，确认了才往下走。
4. **关键帧 → 图生视频**：逐镜生成 3~8 秒；便宜的模型跑节奏测试，留用的那几镜才上贵模型。
5. **720p 试、定稿再重跑 1080p**：只有进片的镜头才重跑高分辨率（成本差一倍多）。
6. **剪辑台**：拼接 + 字幕 + 配音 + BGM。**这类片子的灵魂是台词**（"灭霸记得不要抢我的药""快快救我"），字幕是烧进画面的。
7. **Skill / 模板沉淀**：把固定打法封装成技能，下一集从同一条基线起步。

对照原片的文案（从画面上读到的字幕）：
**「灭霸记得不要抢我的药」「准备好了吗兄弟们」「快快救我」「我看看能不能找到燃烧瓶」「看来只能用这个」「咱们赶快杀过去吧」**
—— 全是《求生之路》式的队友喊话。

**原片的真实结构（2026-11-22 主人更正）**：不是"四人潜入公寓打丧尸"那种一段顺叙，而是
**两个空间来回切**：

1. **现实层**：四个人（灭霸 / 绿巨人 / 钢铁侠 / 火箭浣熊）**在学校宿舍里围坐，启动《求生之路 2》**，边玩边互相喊话；
2. **游戏层**：画面切到**游戏内场景**，但游戏角色被换成这四个人本身 —— 让观众直观看到"他们在游戏里正在干什么"，
   比只靠旁白描述更有画面感、也更好笑。

叙事骨架是「**现实同屏 → 切游戏内的同人演出 → 再切回现实反应**」的循环。
我们那次 chat 拆出来的"潜入公寓 / 围坐开机 / 尸潮来袭"只对上了第 2 步的一半 —— 这是流程缺口，不是模型缺口。

## 二、updream 的产品形状（决定了它的做法）

- B 站自研（2026-04 公测），**不做视频模型**，聚合 45 个第三方模型（Seedance 2.0/2.5、Kling、Wan 3.0、Vidu、MiniMax H3…），逐镜选模型；
- 三件套：**对话式 Agent 读画布** + **节点式画布**（文本/图片/视频节点连线）+ **Skill 技能库**；
- 一致性的三件工具：**角色三视图**、**多机位**、**资产库**（全局复用）；
- **3D 预演台**：一张参考图搭白模场景、多角度截图，在花钱之前定构图与机位；
- **分镜台**：逐镜改描述、换自己的分镜图、**版本历史可回滚**；
- 计费按秒/按张扣积分，**重跑也扣** —— 所以"先用便宜模型确认、只对进片的镜头重跑高清"是它官方建议的省钱打法。

一句话：**它把"人决定什么"和"模型生成什么"拆开了** —— 人定分镜、定角色、挑关键帧、定运镜；
模型只负责把已经定下来的东西渲染成像素。

## 三、我们那次真机复刻：做对了什么、卡在哪

做对的（用「快速模式」一次 chat + 三张现做卡）：

- 分镜拆得对味：**四人潜入废弃公寓 / 围坐启动求生游戏 / 尸潮来袭全员应战**（7s / 6s / 8s）；
- 三张卡（紫金头甲者、giant gr、热点暗地gold）**首帧四人同框**，走廊氛围与原片一致；
- 价签、预览、全部出样片、去剪辑门槛（全部出片）都正常。

卡住的地方（**不是代码 bug，是内容与流程两层**）：

1. **输出侧内容审核**：`第 1 段没出成：output new_sensitive` —— 漫威式角色 + 丧尸题材触发了上游输出审核，
   视频那一发被拒。**这条在我们平台上绕不过去**：要么换原创英雄（去掉品牌化服装/标志），要么换风格（二次元/3D 卡通），
   要么换题材（把"打丧尸"改成不涉暴力的对抗）。
2. **"首帧画完就直接出片"**：我们没有 updream 那种"关键帧先确认、确认了再花视频钱"的停顿 ——
   首帧不对时，人只能等视频出来再重抽（真机上就是等 5 分钟看到 `new_sensitive`）。
3. **没有台词字段**：这类片子的台词是灵魂，我们的分镜只有画面描述；台词只能在剪辑页一条条加字幕补。
4. **没有景别/运镜字段**：分镜是散文式描述，模型自己发挥运镜 —— 与原片"过肩、走廊推镜"这种镜头语言对不上。

## 四、差距表：updream 的做法 ↔ 我们「快速模式」现在有什么

| updream 的一步 | 我们的对应 | 差在哪 |
|---|---|---|
| 分镜台：镜号/时长/场景/**景别/运镜/情绪** | 快速模式①：chat 拆段（标题+时长+一段散文） | **缺结构化镜头字段**（`Proposal` 只有 title/plot/duration） |
| 角色库 + 三视图 + 多机位 | 人物卡（face + body 两张形象图）、快速模式②可现做/挑卡 | 张数策略不同，**没有"三视图/多机位"一键生成** |
| 每镜**先出关键帧、人挑** | 预览段出片前会画首帧，但**画完就直接出视频** | **缺"确认关键帧"的停顿**（最该补的一条） |
| 逐镜选模型、便宜的先跑 | 预览草稿档（MiniMax 480p）→ 升级电影级 | 基本对齐；**升级档默认跟预览同一家**（11-22 已修） |
| 720p 试、定稿重跑 1080p | 样片 → 勾选升级 | 对齐（价签会随帧已存在而降低） |
| 剪辑台：拼接 + 字幕 + 配音 | 剪辑页有字幕/配音/配乐/转场 | 对齐，但**台词要手工敲**（没有从分镜带过来） |
| Skill 沉淀复用 | 卡片 / 卡组 / 模板 / 技能 | 对齐（我们更偏"资产卡"，他们偏"流程 Skill"） |
| 3D 预演台 | 白模模板（从现成视频白模化） | 我们只能"从视频白模化"，**不能从零摆场景** |

## 五、下一步建议（按性价比排序，给后续排期用）

1. **预览段加"关键帧确认"停顿**（小改动、收益大）：首帧画好后先停住，给「就用这张 / 换一张」两颗键，
   人点了才出视频。真机上能省掉"等 5 分钟才知道被拒"的体验。
2. **分镜补台词字段**：chat 拆段时同时给 `lines: string[]`（谁说的 + 说什么），铺节点时带进 `Proposal`，
   剪辑页一键"按台词生成字幕"。这样"同款文案"才真的能复刻。
3. **人物卡加"三视图"**：现做卡时多画一张侧/背视图（或按方舟建议的"大头照 + 全身照"做 A/B），
   多机位一致性会明显好于现在两张。
4. **分镜补景别/运镜**（对齐 repo 里已记的缺口）：`Proposal` 加 `shot: {size, move}`，进提示词前缀。
5. **内容侧**：复刻这类 IP 向短剧，先跟主人确认"原创英雄 + 二次元/3D 卡通"的替代方案，别直接撞审核。
