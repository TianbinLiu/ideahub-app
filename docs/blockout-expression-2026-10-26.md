# 白模模板保留神态（方案 D，2026-10-26）

主人 10-26 第 3 件：「白模模板保留示例视频里的表情 / 神态」。主人「花」之后做了付费小验（Seedance，方舟直连，合计 ¥63.93），
定下上 D：**白模化时顺带记下每个人的神态，套用时按卡名写一句神态**；白模视频一个像素不动，零额外视频费用。

## 一、付费读数

素材两份：M1（二次元，女孩 平静 → 惊讶张嘴 → 眯眼大笑；男孩 看着女孩 → 闭眼皱眉低头 → 回正）、M2（半写实 3D 动画风，男人 大笑 → 皱眉生气 → 叹气低头；女人 认真听 → 似笑非笑 → 捂嘴偷笑）。

| 发 | 做法 | 结果 |
|---|---|---|
| V（看帧 ×3，约 ¥0.05） | 认人表多一列「神态」 | 认人与左右不受影响；女孩两次都写「先平静，后惊讶张嘴，再大笑」，男孩只对一半。模型常在神态列后面多写一个「\|」—— 解析前要先去掉行尾空列 |
| B0（现行白模化，¥8.81） | — | 女孩换成白人偶；**男孩（二次元侧脸 + 眼镜）头没换掉**（生产问题，另记） |
| B1（雕塑脸提示词，¥8.81） | 方案 A | 两个人都留着原来的头发和脸 ⇒ **A 判失败**，不上 |
| A0（现行骨架，¥7.90） | — | 换人干净；女孩该惊讶的那一拍是闭嘴笑（神态大半丢了） |
| D（骨架 + 神态句，¥7.90） | 「神态：青璃先平静，后惊讶张嘴，再大笑；赤野先惊讶张嘴，后垂眼抿唇。」 | 惊讶张嘴、眯眼笑、张嘴大笑三拍都出来；换人同样干净 ⇒ **D 明显胜过 A0** |
| B0' / A0' / D'（M2，¥24.61） | 同上 | 半写实素材上白模本身就留住了大半神态；A0' 与 D' 几乎一样 —— D 不增不减 |

结论：D 在「白模把脸抹平」的素材上补回神态，在本来就留得住神态的素材上无害。第一版只在 **≤ 3 个角色位**的模板上写（多人群像没验过）。

顺带记下的两条生产问题：① 现行白模化在「二次元侧脸 + 眼镜」的人身上会漏换头；② 卡图 / 参考图刚传上图床的几秒里，方舟偶发同步 400「invalid image format received ""」（不扣钱，重发就过）。

## 二、怎么做的

- **服务端（server #133，等主人「合」）**：白模化阶段一的认人表多一列神态，存成 `markExprs`（与 `markSlots` 按下标对齐），跟着模板回包；
  核对面板改角色位时按人搬、重新认人时清掉。契约见 `docs/api-contract.md` 模板形状里 `markExprs` 那几行。
- **App（这一份）**：
  - 规则只在 `data/blockoutExpr`（零依赖，构建里 `scripts/check-blockout-expr.mjs` 实跑）：`exprIn` 清洗（绑定记号 / 分隔符 / 行尾「|」/ 列名前缀，超长丢整拍）、
    `exprLineOf` 拼句（只写挂了卡且有神态的位子；同一张卡挂两个位子的不写；角色位多于 3 个整句不写；写法逐字照 D 那一句）、`fitsExpr`；
  - 字段四处一起搬（`apiToTemplate`、`NewTemplate`、`adoptBlockoutTemplate`、`refreshRemoteTemplate` 的 mine 与 shared 两份），重新认人那一跳跟着清；
  - `flowStore` 建角色位时取 `markExprOfLabel`（唯一取值处），`BlockoutCastSlot.expr` 必填；
  - `blockoutPrompt`：括号描述先定、神态句后定（放不下整句不写），排在作者那句话之后、「不要出现字幕」之前；合成时系统提示词要它逐字保留，丢了补回去（只补不拒）；
  - 核对面板每一行下面只读显示「神态：…」。
- **不变的**：没有 `markExprs` 的模板（所有老模板、编号方案、自己传白模片那条路、服务端 #133 上线之前）套用提示词与今天逐字节相同；报价不变（看帧还是那一次对话）。
