# 按 CSCI 187 的可用性 / UX 检查单走查 App（2026-10-14）

> 主人 10-14：「按照 CSCI 187（The Design and Management of Software）里的内容和要求对 app 的 UI 等做优化」。
> 这份记录两件事：课程给的尺子是什么、拿它量 App 量出了什么、改了哪些；没改的按优先级列成清单。
> 课程讲义本身不抄进仓库（版权归教授），下面只写**检验问题**，那是通用的 UX 术语。

## 一、尺子

课程把一屏的 UX 拆成六个框架，每个框架一个检验问题：

| 框架 | 管的东西 | 检验问题 |
|---|---|---|
| 布局与结构 | 顶栏、页签、网格、分组 | **可扫视**：一眼能看出这一页怎么组织、该去哪儿吗？ |
| 视觉层次 | 字重、字号对比、留白、焦点 | **优先级**：视线会不会先落到主要动作上？ |
| 输入与控件 | 按钮、输入框、勾选、滑杆、下拉、开关 | **控制感**：控件看得出能点、点得中、行为可预期吗？ |
| 系统反馈与状态 | 按下态、加载圈、进度条、成功 / 失败提示 | **响应性**：刚发生了什么、在等什么，立刻能知道吗？ |
| 视觉风格 | 配色、字体、图标集、边线、阴影 | **可读与品牌**：字看得清、风格一致、认得出是谁吗？ |
| 信息 | 按钮文案、辅助文字、行内指引、空态文字 | **清晰**：话简洁、直觉、没有行话吗？ |

另外三条也拿来量了：
- **数字可供性与惯例**：控件要长得像控件（视觉胜于文字）；箭头 = 有下一层；**圆 = 单选、方 = 多选**；手机上没有「悬停」。
- **Goodwin 的「好产品礼仪」**（教材第 12 章）：不要求确认、而是提供**撤销**；不用无关的事打断；让错误不可能发生；不让用户记东西；合理的默认值。
- 经验法则：**简单 > 易用 > 直觉**；以及讲义点名的 AI 两个弱项 —— 违反可用性惯例、对细微的用户需要不够体贴。

## 二、怎么量的

- 应用内浏览器按手机视口（375×812）逐页走：首页、登录、创作入口、简约模式、3D 工坊 + 铸段窗、设置、草稿箱、模板市场、消息、作品页。
- 三份只读审计并行（各管两个框架）：控件与惯例；反馈 / 状态 + 布局 / 层次；文案与行话。合计约 90 条发现。
- 筛法：**只留正式包在手机上真会撞上的**（dev / mock 假象、three.js 画布内部、后台页不算），再按「改了不与仓库既有约定打架」挑。

## 三、改了什么（都在这次 PR 里）

| 改动 | 在哪 | 框架 | 为什么 |
|---|---|---|---|
| 删草稿 → **先删、再给 6 秒「撤销」**（`data/drafts.trashDraft` + 轻提示带键 `data/toast` / `components/Toast`） | 草稿箱、个人页的草稿操作单 | 礼仪：撤销而不是确认 | 确认卡人人点「确定」，拦不住手滑；撤销才真能拿回来。**带已出片段的草稿仍先问一句**（花过钱、6 秒未必看见），两道都在 |
| 协议勾选框由圆改**方**，框 18px、命中区 36px，整行文字也能点 | 登录页 | 惯例 / 控制感 | 圆是单选的记号；原来 16px 的圆点手指点不中 |
| 「没有账号？用邮箱注册」摆到密码框下面；「忘记密码」加下划线与命中区；注册 / 重置分段控件用全 app 的选中态 | 登录页（远端模式） | 可扫视 / 控制感 | 第一次装 App 的人在登录页上找不到一个写着「注册」的字 |
| 第三方登录键 busy 时灰掉；「发送验证码」自己说「发送中…」；登录主键加按下态 | 登录页 | 反馈 | 连点两下会起两次授权；原来忙的只有主键，不知道是哪件事在跑 |
| 个人页五枚页签**图标下面加名字** | 个人页 | 可扫视 | 草稿是把锁、卡片与卡组两枚几乎一样，新用户认不出 |
| 设置页五个框**加分组标题**（个性化 / 账号 / 这台设备 / 帮助与 AI 伙伴 / 协议与须知） | 设置页 | 可扫视 | 分组名原来只在源码注释里 |
| 简约模式：第 3 步的拒绝画在「出片」键**正上方**；进度下面加「可以离开这一页，出片好了会在顶上提醒你」；第 1 步两块砖带 › 与按下态；价签带单位（「⚡ 出片（1.2k token）」） | 简约模式 | 反馈 / 惯例 / 清晰 | 键在屏幕底、错误在顶，人盯着键看不到那句；几分钟的出片要说清能走开；光一个「1.2k」分不出是什么 |
| 出片胶囊**不在开炉的那一面上显示**；关闭键命中区 36px | `GenerationPill` | 反馈 / 控制感 | 简约页与工坊各自画着进度，胶囊在那儿只会压住顶栏那排键 |
| 模板市场第一次取货时画**加载圈**（`templates.sharedListLoading`），不再说「市场上还没有公开的模板」 | 模板货架 | 反馈 | 第一次进那一两秒屏幕上写的是「没有」，读到的是「这产品没内容」；老服务端 / 离线得出结论就收掉，不会卡在圈上 |
| 发现页「没搜成」挪到网格**上面** | 发现页 | 反馈 | 原来排在几十条兜底结果之后，一屏滚不到 |
| 个人页「正在取你的作品 / 收藏…」配加载圈 | 个人页 | 反馈 | 一行字分不出"在取"和"卡住了" |
| 首页「关注」页签没登录时的键改成「登录」 | 首页 | 清晰 | 那句说的是「登录后…」，键却写着「去推荐流」 |
| 首页作者头像下那颗关注 + 号命中区放到 44px | 首页 | 控制感 | 20px、贴着头像键，点偏就进了主页 |

| 创作入口工坊卡：第三条卖点改「每出一段自动存草稿，随时接着做」；主键改「开始做完整作品」 | 创作入口 | 清晰 | 原来写的是实现（「3D 桌面与工作流画布是同一条流水线的两个面」）与去处（「进铸卡桌面」），不是用户得到什么 |

| 模板详情页主键灰着时**把原因写在键下面**，套餐那一档给「去升级」 | 模板详情页 | 反馈 | 原来只在 title 里 |
| 创意工坊：卡片上的 ✕ 一直显示（原来 hover 才出现，手机上从没显示过）；「＋ 添加」做成胶囊；卡组行的「编辑 / 删除」做成胶囊 | 创意工坊 | 惯例 / 控制感 | 手机没有 hover；16px 高的裸文字分不出哪个是键 |
| 剪辑页顶栏「下一步」改「合成并去发布」 | 剪辑页 | 清晰 | 它做的是先合成整条片再去发布页 |
| 运镜多选芯片：选中带 ✓、实底、`aria-pressed` | 画布 | 惯例 | 多选要有勾；淡底 + 细框那种选中态全 app 已收掉 |
| 两处用户文案里的「r2v」去掉；一句 30 多字的轻提示延到 7 秒 | 模板 / 发布 | 清晰 / 反馈 | 工程缩写；1.8 秒读不完 |

## 四、没改、留给主人定的（按框架，严重的在前）

**视觉层次 / 布局**
1. 发布页：预览占到 72vh，标题框在首屏之下，「发布」键在约 13 块内容之后（三四屏）。建议预览缩成缩略条、标题放最前、发布键做成吸底栏。
2. 画布的「🎬 完成视频」画在画布坐标里，两段以上就在屏幕外，要平移才找得到。建议钉在画布边上。
3. 作品页有四颗「去创作」类的键（顶栏「我也要创作」、「查看制作过程」、金色「做同款」、品牌色「用这套卡去创作」），两颗实底，没有一颗是主的。建议只留「做同款」实底。
4. 个人页首屏唯一的实底键是「充值 / 套餐」，创作与草稿入口在页签下面约 520px 处。
5. 工坊方案面板约 12 块叠着，主键在滚动区底部，删段键排在主键前面。
6. **与仓库约定有张力的一条**：CLAUDE.md 规定选中态与主键同用实底 `bg-brand`，课程的「优先级」检验会问"视线先落到哪"—— 节点面板上同时有三块品牌色（模式芯片、时长芯片、生成键）。改不改是约定层面的决定。
7. 创作入口是一张正反面的卡：简约模式（最快的首次上手路）藏在背面，只靠右上角一枚 11px 的翻面钮。

**反馈与状态**
8. 点赞 / 关注 / 收藏在远端失败时**静默回滚**：`emitApiError` 全 app 没人监听，首页条目又各自持有一份本地状态，于是心还是红的、数字还是 +1。建议首页条目改从数据层重读 + 回滚时一条轻提示。
9. 圈选改图的底图加载失败只进 `console.warn`，画布空着、「存入标注」照样能按（会拿一张黑图去付费重画）。
10. 发布之后的上传进度只在个人页横幅里，作品页上什么都不说、也没登记进后台任务胶囊。
11. 首页「关注」页签、作品页评论区第一次取时先显示"没有"。

**输入与控件（系统性）**
12. 约 925 颗按钮里只有 8% 有按下态；67 颗图标键手写成 44px 以下（28 颗没有读屏名），集中在 projection / NpcDialog / FlowCanvas；7 条错误横幅各自手画一枚 12–14px 的 ✕ —— 值得收成一个共用的 ErrorBar。
13. 时长 / 档位选择器在三四处长成三四种样子（圆角方、胶囊、金色选中态），值得收成一个共用芯片组件。
14. 「为什么灰着」只写在 title 里的还有：画布模式页签、`SegSettings` 的时长 / 画幅芯片、`PlanBoard`。
15. 卡片详情放大层的「删掉这张」一下就删（常是付费画的图），没有确认也没有撤销。

**信息（文案）**
16. 首次创作路径上叠着两套私有词汇：铸 / 炼 / 法阵 / 一炉 / 卡位（品牌隐喻）与 白模 / 推演 / 承接 / 直出 / 节点 / 契约（工程词）。新用户出第一条片之前要遇到约 10 个没定义的词。品牌隐喻可以留给铸卡师的台词，按钮与状态行用大白话。
17. 一个概念多个名字：「工坊」指两个不同的屏（底栏的创意工坊 / 3D 铸卡桌）；「生成这一段」有 5 种键名；工程叫 工作流 / 画布 / 流水线；人物卡也叫角色卡；「做同款」有两种意思。
18. 钱：约 49 颗动作键上只有「（1.2k）」没单位、没动词；token 在 App 里从没解释过；同一种货币叫 token / 余额 / 额度 / 钱 / 积分；⚡ 既是 token 又是「出片」。这次只给简约模式的两颗键加了单位。
19. 102 条非帮助文案超过 60 字，多在解释边角情况而不是下一步。
20. 内部用语漏到界面：方舟（19 处）、火山（21 处）、「这台服务器 / 服务端升级」（37+）、HTTP 状态码、约 23 处原样拼进 `e.message`、出片进度里的「生成契约」一步带参数倾印。
21. 新手引导（`components/guide/tours.tsx`）每步正文 100–150 字，是主人逐条核过事实的内容；课程会说"简洁"，建议每步压到两句、细节留给 `?`。没动是因为那份文案的每一句都"会被用户当真"，改要逐条对实现。

## 五、怎么验的

- `npm run build` 全绿（tsc、lingui extract、十几道检查脚本、`check-i18n` 缺译 0）。
- 浏览器（离线 mock、375×812）：设置页分组标题、个人页页签名字、简约第 1 步的 ›、创作入口文案、登录页方勾选框与下划线链接各截了图。
- 删草稿 → 撤销走了一遍：删后列表 0 条，点「撤销」回到 1 条、同一个 id、正文原样读得回。
- 带键的轻提示单独调一次 `showToast(..., { label, run })` 看过样子。
